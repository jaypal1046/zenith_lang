# 3D Mech Warfare Simulator — Zenith Game Sample

A 3D Heavy Mech Warfare Simulator project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Heavy BattleMech & Reactor Heat**: Heat dissipation, reactor overheating thresholds, AC/20 Auto-cannon, and LRM missile salvos.
- **Destructible Urban Environment**: Building collapse fracture physics, smoke volume particles, and impact camera recoil.
- **Cockpit HUD & Spatial Audio**: 3D HRTF explosion reverb zones and controller haptics.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/mech_warfare/main.zen): Main cockpit game loop & application entry point.
- [mech_unit.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/mech_warfare/mech_unit.zen): BattleMech entity & weapon heat management.
- [battlefield.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/mech_warfare/battlefield.zen): UrbanBattlefield environment & destructible building physics.

## 🎮 How to Run
```bash
zenith run examples/mech_warfare/main.zen
```
