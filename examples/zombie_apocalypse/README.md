# 3D Zombie Apocalypse Survival — Zenith Game Sample

A 3D Zombie Apocalypse Horde Survival game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Survivor Player & Barricades**: Shotgun weapons, pipe bomb AoE explosions, barricade repair, and wood plank crafting.
- **Zombie Swarm AI & Destruction**: 75+ zombie flocking swarm behavior, barricade assault damage, and ragdoll physics.
- **Night Wave Survival**: Dynamic night survival wave counters and survival mechanics.

## <ctrl42> Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/zombie_apocalypse/main.zen): Main survival loop & application entry point.
- [survivor.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/zombie_apocalypse/survivor.zen): SurvivorPlayer entity & barricade crafting.
- [zombie_swarm.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/zombie_apocalypse/zombie_swarm.zen): ZombieSwarmAI & barricade assault physics.

## 🎮 How to Run
```bash
zenith run examples/zombie_apocalypse/main.zen
```
