# 3D Stealth Ops Infiltration — Zenith Game Sample

A 3D Stealth Infiltration Agent game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Operative Agent & Noise Management**: Crouch mechanics, decibel noise levels, EMP grenades, and silent takedowns.
- **Guard Sight & Hearing Perception**: 90° FOV sight cone checks, decibel noise hearing thresholds, and alert state transitions.
- **Shadow Occlusion & Spatial Audio**: Shadow volume hiding and 3D HRTF audio.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/stealth_ops/main.zen): Main infiltration loop & application entry point.
- [stealth_agent.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/stealth_ops/stealth_agent.zen): StealthAgent entity & noise management.
- [patrol_guard.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/stealth_ops/patrol_guard.zen): PatrolGuardAI sight cones & hearing sensors.

## 🎮 How to Run
```bash
zenith run examples/stealth_ops/main.zen
```
