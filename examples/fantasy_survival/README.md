# Fantasy Spell Survival — Zenith Game Sample

A 3D Fantasy Magic Survival game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Archmage Player & Mana Regen**: Mana regeneration mechanics, spell cooldowns, Fireball & Ice Nova AoE casting.
- **Monster Horde Flocking AI**: Swarm flocking behavior advancing toward the player using A* NavMesh pathfinding.
- **Particle Explosions & Audio**: High-density Fire/Ice magic particle effects and 3D HRTF sound effects.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/fantasy_survival/main.zen): Main game loop & wave spawner.
- [mage_player.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/fantasy_survival/mage_player.zen): ArchmagePlayer entity & spellcasting logic.
- [monster_horde.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/fantasy_survival/monster_horde.zen): MonsterHordeGroup AI & swarm movement.

## 🎮 How to Run
```bash
zenith run examples/fantasy_survival/main.zen
```
