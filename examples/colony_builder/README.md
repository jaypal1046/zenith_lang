# 3D Sci-Fi Colony Builder — Zenith Game Sample

A 3D Sci-Fi Space Colony Builder & City Sim game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **3D Grid & Life Support System**: Bio-Dome grid placement, solar power grid balancing, and oxygen production.
- **Colonist AI & Morale**: Colonist population state machine, food supply consumption, and morale tracking.
- **PBR Solar Shaders & Audio**: PBR solar panel shaders and 3D ambient wind soundscapes.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/colony_builder/main.zen): Main simulation loop & application entry point.
- [colony_grid.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/colony_builder/colony_grid.zen): ColonyGridSystem & life support power grid.
- [colonist_ai.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/colony_builder/colonist_ai.zen): ColonistAI population & food supply tracking.

## 🎮 How to Run
```bash
zenith run examples/colony_builder/main.zen
```
