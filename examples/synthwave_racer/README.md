# 3D Neon Synthwave Racer — Zenith Game Sample

A 3D High-Speed Neon Cyberpunk Synthwave Racer game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Cyber Supercar & Nitro Boost**: Vehicle speed physics, nitro boost acceleration (340 km/h top speed), and neon tail-light ribbon particle trails.
- **Neon Grid Track & Retro Sunset**: Wireframe grid shaders, retro sunset horizon gradients, and 128 BPM adaptive synthwave music stem layers.
- **Audio Engine**: 3D HRTF engine acceleration sounds and dynamic BGM crossfading.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/synthwave_racer/main.zen): Main race loop & application entry point.
- [neon_car.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/synthwave_racer/neon_car.zen): CyberSupercar entity & nitro boost system.
- [synth_grid_track.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/synthwave_racer/synth_grid_track.zen): SynthGridTrack neon wireframe environment & BGM stems.

## 🎮 How to Run
```bash
zenith run examples/synthwave_racer/main.zen
```
