# 6DoF Space Dogfight Simulator — Zenith Game Sample

A High-Octane 6DoF Space Dogfight Simulator project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **6DoF Flight Physics**: 6 Degrees-of-Freedom pitch/yaw/roll thrusters, afterburner boost, and twin-linked laser cannons.
- **Procedural Asteroid Field**: Perlin noise density distribution for 150 procedural asteroids.
- **Engine Exhaust Trails & Audio**: Particle exhaust trails and 3D HRTF engine thruster sound effects.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/space_dogfight/main.zen): Main flight loop & application entry point.
- [starfighter.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/space_dogfight/starfighter.zen): Starfighter entity & 6DoF flight physics.
- [asteroid_field.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/space_dogfight/asteroid_field.zen): AsteroidSector environment & procedural density.

## 🎮 How to Run
```bash
zenith run examples/space_dogfight/main.zen
```
