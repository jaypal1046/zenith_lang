## 📚 Learning Path

### For Beginners

1. **Start Here**: Read the [README](README.md) to understand what Zenith is
2. **Install**: Follow the [Installation Guide](docs/getting-started/installation.md)
3. **First Steps**: Complete the [Quick Start](docs/getting-started/quickstart.md)
4. **Learn Syntax**: Study the [Language Guide](docs/language-guide/syntax.md)
5. **Practice**: Try examples from the [Cookbook](docs/cookbook/hello-world.md)

### For Experienced Developers

1. **Overview**: Skim the [README](README.md) for unique features
2. **Deep Dive**: Read [Advanced Topics](docs/advanced/memory-management.md)
3. **Build Something**: Pick a [Cookbook Recipe](docs/cookbook/todo-app.md)
4. **Contribute**: Check out the [Contributing Guide](CONTRIBUTING.md)

### For Mobile/Web Developers

1. **UI Basics**: Start with [UI Fundamentals](docs/ui/fundamentals.md)
2. **Target Platform**: Read about [Web](docs/targets/web.md) or [Mobile](docs/targets/mobile.md)
3. **Examples**: Build the [Todo App](docs/cookbook/todo-app.md)
4. **Deploy**: Learn about [Cross-Platform Deployment](docs/targets/cross-platform.md)
