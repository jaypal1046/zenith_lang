# 3D Pirate Naval Warfare — Zenith Game Sample

A 3D Pirate Naval Warfare & Ocean Ship Simulation game project built using Zenith Language & Engine capabilities.

## 🚀 Key Features Demonstrated
- **Galleon Pirate Ships & Broadside Cannons**: Port and starboard 16-cannon broadsides, hull water level integrity, and sail wind angle adjustment.
- **Ocean Wave Shader & Buoyancy**: Gerstner wave displacement, subsurface scattering shaders, and hydrodynamic buoyancy force calculation.
- **Cannon Water Splashes & Audio**: Bow wave foam particles and 3D HRTF ocean wave sound effects.

## 🕹️ Project Structure
- [main.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/pirate_naval_warfare/main.zen): Main naval battle loop & application entry point.
- [galleon_ship.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/pirate_naval_warfare/galleon_ship.zen): GalleonShip entity & broadside cannons.
- [ocean_water.zen](file:///c:/Jay/_Plugin/zenith_lang/examples/pirate_naval_warfare/ocean_water.zen): OceanWaterSim Gerstner waves & buoyancy solver.

## 🎮 How to Run
```bash
zenith run examples/pirate_naval_warfare/main.zen
```
